# SoundCloud Wave 0.22.0 — резервное подключение

Подготовлены локальный CONNECT→WSS туннель, Cloudflare Worker с разрешёнными адресами SoundCloud/CDN, автоматическая проверка обычного и резервного маршрута, режим принудительного Worker, настройка и проверка подключения. Worker пока не развёрнут: нужны аккаунт Cloudflare, адрес и личный ключ. По умолчанию модуль выключен.

В настройках есть кнопка «Файлы Worker и инструкция». Папка с worker.mjs, protocol.mjs, wrangler.toml и README.md включена в установщик. Инструкция также поставляется отдельно в архиве Worker.

Автоматический режим реагирует на ошибку загрузки и HTTP 403/451/5xx, проверяет зависшую загрузку примерно через 18 секунд и реагирует на сетевые ошибки API/медиа. Проверяет основной маршрут и доступность Worker, прежде чем менять маршрут. При ошибках обоих маршрутов не перезапускает приложение по кругу; проверки ограничены интервалом две минуты. Активный штатный плеер при автоматическом переключении не прерывается; переключение откладывается. Успешный переход повторно загружает страницу SoundCloud, не меняет системную сеть и не удаляет вход в аккаунт.

Исправлено применение обычного прокси к сессии выбранного аккаунта. Публичные метаданные волны теперь тоже используют сетевую сессию клиента. Ключ Worker шифруется через Electron safeStorage, не выводится в HTML настроек и не вшивается в сборку. Добавлен UTF-8 для страницы настроек.

Проверки: 158 модульных тестов, включая локальный сквозной CONNECT/WSS тест на 2 МиБ, ограничение целевых адресов и защиту от повторных переключений. Проверки Electron подтверждают PAC-маршруты только SoundCloud/CDN, выбранную сессию аккаунта, шифрование ключа, работу новой панели и её кнопок. Проверки волны/импорта выполняются отдельно. Живой Cloudflare Worker не тестировался, потому что он ещё не развёрнут.

Ограничения и установка описаны в cloudflare/soundcloud-relay/README.md. Cloudflare connect() запрещает соединения к IP самой Cloudflare; нет выбора страны выхода и гарантии обхода всех региональных ограничений каталога. Это подготовленный резервный транспорт, не обещание доступа к каждому треку в каждой стране.
