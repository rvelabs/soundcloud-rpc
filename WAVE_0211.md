# SoundCloud Wave 0.21.1 — частичный импорт

- Кнопка «Создать из найденных» доступна, как только появились выбранные совпадения: не нужно ждать весь большой плейлист. Поиск останавливается, завершённые совпадения сохраняются, затем начинается создание.
- Обычная отмена поиска тоже сохраняет найденную часть; непроверенные строки помечаются отдельно.
- Не найденные треки не блокируют найденные. Сбой проверки доступности отдельной записи не отменяет всю проверку.
- Если первый найденный трек не добавился, клиент пробует создать/найти плейлист через следующий доступный трек. Последующие ошибки собираются в отчёт, успешные добавления сохраняются.
- После частичного успеха результаты остаются в окне; подтверждённые записи отмечаются «Добавлено в плейлист» и снимаются с выбора. Неудачные можно повторить.
- Повторный поиск и добавление под тем же названием использует существующий единственный плейлист и штатную проверку наличия записи: дубли не создаются. Если плейлистов с одинаковым названием несколько, нужно уточнить название.
- Автоматического продолжения незавершённого поиска после создания нет: для оставшейся части запустите поиск снова. Уже найденные неподтверждённые совпадения можно повторно добавить без нового поиска.
- Если нет ни одного доступного совпадения или SoundCloud не подтвердил ни одну запись, клиент сообщает об ошибке и не заявляет об успешном импорте. Найденные данные остаются для повторной попытки в текущем окне приложения.

Проверка: 152 модульных теста; 20 сценариев Electron UI, включая остановку поиска после одного совпадения, создание найденной части и сохранение оставшихся строк. TypeScript и ESLint нового модуля проходят. Проверка записи настоящего аккаунта в этой версии не выполнялась: штатный адаптер сохранения не менялся, сбои создания и добавления проверены отдельно через подставляемые операции.
