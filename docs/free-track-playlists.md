# Плейлист по треку без Claude

Встроенный вариант функции из `ai-playlist-for-sxs.zip`. Работает в Windows-клиенте Rust + WebView2. Claude Code,
подписка Claude, ключи Claude/OpenAI, MCP-сервер и отдельная локальная ИИ-модель не нужны. Нужен интернет и обычный вход
в SoundCloud для чтения своих предпочтений и сохранения приватного плейлиста.

## Использование

1. Открыть меню `⋯` у трека → **Плейлист по треку**.
2. При желании написать условия, выбрать 10–40 треков и нажать **Подобрать треки**.
3. Просмотреть результат, снять отметки с ненужных треков, изменить название.
4. Нажать **Создать приватный плейлист**. До этого шага ничего не создаётся.

Примеры: `спокойнее, без вокала`, `побыстрее, больше баса`, `в основном из моих лайков`, `только из моих лайков`,
`jungle, без рэпа`, `без «Имя исполнителя»`, `calmer, no vocals`, `more bass`. Поддерживаются настроение, темп, характер
звучания, русский/иностранный язык, инструментальная музыка, распространённые жанры, исключения и предпочтение лайков.
Распознанные условия видны в диалоге; неизвестные слова отдельно перечисляются и не интерпретируются. Противоречивые
условия нужно уточнить. Это разбор поддерживаемых условий, а не универсальное понимание свободного текста.

## Как выбираются треки

- Исходный трек проверяется через существующий каталог SoundCloud.
- Кандидаты берутся из похожих треков, станции исходного трека и лайков. При нехватке добавляется одна страница похожих
  треков и один поиск по музыкальным признакам.
- Используется существующий движок рекомендаций: исходный трек остаётся якорем на всей длине списка. Учитываются
  сохранённые лайки, реакции и исключения, а также блокировки исполнителей SoundCloud.
- Сохранённые аудиопризнаки и отпечатки переиспользуются. Новый декодер, скрытое окно и фоновая модель ради этого
  диалога не запускаются. Для неизученных треков остаются метаданные и связи каталога.
- Пожелания фильтруют список, лайки и звучание могут повысить приоритет. Повторы записи удаляются, число треков одного
  исполнителя ограничено; перед сохранением проверяется доступность полного потока.
- Если близких доступных вариантов меньше запрошенного, показывается меньший список. Случайные жанры для заполнения не
  добавляются. Доступность подтверждается метаданными SoundCloud, а не прослушиванием каждого трека.

Подготовка не изменяет обучение «Моей волны», её очередь и настройки. Чтения выполняются в фоне, не более двух
одновременно. Есть отмена и общий предел ожидания 60 секунд. Токен SoundCloud остаётся в существующем клиенте; он не
передаётся Claude, отдельным процессам или дополнительным сервисам.

## Временные плейлисты

Автоудаление по умолчанию выключено. Можно выбрать 12 часов, 1, 3 или 7 дней. Срок проверяется при работающем клиенте;
после следующего запуска просроченные записи тоже проверяются. Расписание хранится в отдельном профиле аккаунта
`playlists-<id>`, а не в профиле обучения волны. Удаляется только принадлежащий текущему аккаунту приватный плейлист с
теми же названием и составом. Переименование, изменение состава, публикация или кнопка **Оставить навсегда** отменяют
автоудаление. При ошибках выполняется не больше пяти попыток. Плейлисты, созданные вручную, в расписание не добавляются.

## Проверка разработчиком

`npm run native:test:frontend` — подбор, пожелания, профиль, смена аккаунта, отмена, дубли, автоудаление.

`npm run native:build` и `npm run native:smoke` — Windows EXE и изолированный WebView2: диалог RU/EN, ширины 320–960 px,
предпросмотр без записи, сохранение выбранных треков, отмена автоудаления. Smoke использует тестовый каталог и отдельный
профиль: реальные плейлисты пользователя не создаются и не удаляются.
