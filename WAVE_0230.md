# SoundCloud Wave 0.23.0 — мастер настройки Worker

Настройки → Резервное подключение SoundCloud → Создать и настроить Worker автоматически.

Пользователь входит в Cloudflare через браузер, создаёт ограниченный API-токен и вставляет его в мастер. Приложение получает доступные аккаунты; пользователь проверяет выбор и нажимает создание. Дальше автоматически: чтение существующего workers.dev, регистрация адреса при его отсутствии, генерация отдельного ключа туннеля, загрузка worker.mjs и protocol.mjs через официальный API с секретной привязкой RELAY_TOKEN, включение HTTPS, сохранение адреса и зашифрованного ключа. Node.js и терминал для этого способа не нужны.

API-токен используется только в памяти на время настройки, в поле интерфейса очищается сразу и не возвращается из main в renderer. Срок сеанса — 10 минут; есть явное забывание. После успеха в интерфейсе показан HTTPS-адрес, ключ не показывается. Автоматический режим применяется сразу при первоначальной настройке с выключенным резервным подключением и без обычного прокси. При изменении уже существующего подключения предлагается перезапуск для применения.

Ручные поля адреса и ключа сохранены. Можно использовать уже развёрнутый Worker. Из настроек доступна папка с файлами и обновлённой инструкцией.

Проверки: модульные сценарии существующего и отсутствующего subdomain, отказ прав без попытки создания домена, оба модуля и secret_text в multipart, отказ включения HTTPS, повторное использование имени/ключа, очистка токена; Electron проверяет полный путь от авторизации через выбор аккаунта до автоматического заполнения адреса и пустого поля ключа. Живого развёртывания нет: токен реального Cloudflare не предоставлялся. Ограничения транспорта 0.22.0 сохраняются.
